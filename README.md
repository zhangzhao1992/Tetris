# 经典俄罗斯方块

一个可直接发布的网页版俄罗斯方块，支持电脑键盘、平板和手机触控。

## 本地打开

直接用浏览器打开 `index.html` 即可游玩。

## 发布到网上

把下面这些文件上传到任意静态网站服务即可：

- `index.html`
- `styles.css`
- `game.js`

可用的平台包括 GitHub Pages、Netlify、Vercel、Cloudflare Pages，或普通网站空间。无需安装依赖，也无需构建。

## 操作

- 方向键左右移动
- 上方向键旋转
- 下方向键加速下落
- 空格直接落下
- 手机和平板可使用屏幕按钮，也可在棋盘上滑动或轻点
